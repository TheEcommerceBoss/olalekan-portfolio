# Olalekan Ajimoti · Portfolio website

Playful, futuristic personal site built with React 19 + Vite.

- **@shadergradient/react** animated hero gradient
- **@react-three/fiber + drei** floating glass objects and the scroll-driven particle world
- **@paper-design/shaders-react** liquid-metal monogram and mesh-gradient backdrop
- **liquid-glass-react** navigation and buttons

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Push to GitHub and import the repo at vercel.com (framework: Vite). No settings needed.
